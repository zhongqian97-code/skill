# Deliverables Checklist

Use this checklist when running `ai-delivery-loop`.

## Research note
- Requirement summary
- Key assumptions
- Plan 1 prototype path
- Plan 2 engineered path
- Plan 3+ industry variants
- Recommendation
- Risks and unknowns

## Design doc
- Scope and non-scope
- Module breakdown
- Main flow
- Error / failure paths
- Test plan

## Coding
- Feature-to-module mapping
- Test-first or test-guarded implementation

## Verification note
- Design point
- Code location
- Test coverage
- Manual check result

## Review summary
- Findings
- Design updates caused by findings
- Fix status
- Residual risk
