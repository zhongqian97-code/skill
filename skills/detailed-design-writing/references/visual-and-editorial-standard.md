# Visual and Editorial Standard

A detailed design is one coherent communication artifact, not a concatenated bundle.

## Hard minimum

- one early system summary Mermaid diagram;
- one primary behavior diagram per F-ID;
- triggered state, ER, sequence, flow, and deployment diagrams;
- every diagram maps to exact contracts and has a text alternative;
- one H1, one status block, one hierarchy, one glossary;
- one canonical definition for every contract/data/state/decision;
- learner and implementer reading paths and blind-read checks.
