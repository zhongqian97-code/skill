# Usability and Synthesis Gates

## U1 Single artifact

PASS requires one H1, one status/source block, one TOC, continuous numbering, one glossary, and no companion-file dependency. Search for repeated H1s, duplicated definitions, restarted sections, embedded report identities, and abrupt voice changes.

## U2 Progressive disclosure and navigation

PASS requires a five-minute layer and feature implementation layer. Verify learner/implementer/reviewer paths and the two-jump navigation rule.

## V1/V2 Visual coverage

Build an F-ID ↔ D-ID matrix. Every F-ID requires a primary behavior diagram. Check triggered system/context/component, state, ER, sequence/flow, and deployment views.

## V3 Diagram truth

Render Mermaid. Map every key node/edge to normative contracts and evidence. Compare names, directions, states, failures, tables, and sync/async semantics across views.

## P1 Vertical closure

For each F-ID verify UI, contracts, backend, data/async, failure/recovery, security/ops, tests, and evidence. A horizontal chapter existing elsewhere is not proof unless the F-ID links to it.

## M1 Synthesis

Multiple agents may collect structured facts. The final document must show one editorial model. Concatenation, appended reports, repeated normative definitions, and unresolved terminology conflicts fail.
